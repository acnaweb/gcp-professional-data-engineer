# Aula 2 — Padrões de Streaming

## Objetivos
- Diferenciar event time e processing time.
- Entender windowing, watermark e late data.

## Conceitos
```text
Event Time ≠ Processing Time
```

Windowing:
- Fixed
- Sliding
- Session

Late data:
- Watermark
- Allowed lateness
- Triggers

## Questões
Fraude em tempo quase real com eventos fora de ordem?  
**Use processamento orientado a event time com windowing/watermarks.**
