# Aula 4 — Transferência de Dados

## Objetivos
- Escolher Storage Transfer Service, Transfer Appliance e outras opções.

## Matriz
| Cenário | Solução |
|---|---|
| Transferência online entre object stores | Storage Transfer Service |
| Volume muito grande/offline | Transfer Appliance |
| Ingestão contínua de eventos | Pub/Sub |
| CDC relacional | Datastream |

## Regra
Escolha ferramenta pelo padrão de ingestão, não apenas pelo volume.
