# Aula 3 — Dataproc e Spark

## Objetivos
- Entender quando usar Dataproc.
- Diferenciar cluster tradicional, serverless e Dataflow.

## Use Dataproc quando
- Há código Spark/Hadoop existente.
- Ecossistema open source é requisito.
- Migração com pouca reescrita.

## Compare
| Necessidade | Serviço |
|---|---|
| Apache Beam gerenciado | Dataflow |
| Spark/Hadoop | Dataproc |
| SQL analytics | BigQuery |

- [ ] Sei quando escolher Dataproc
